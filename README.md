# 🎙️ Voice-Controlled Smart Home Automation System

An offline, secure, and reliable smart home automation system built using **Arduino Uno**, **VC-02 Voice Recognition Module**, and **C/C++**. This project allows users to control household appliances (Lights, Fan, TV, and All Devices) seamlessly using simple voice commands without needing an active internet connection.

---

## ✨ Key Features
* **100% Offline Operation:** Works locally via the VC-02 voice module without internet or cloud dependency.
* **Multi-Device Control:** Manages individual appliances as well as "All Devices ON/OFF" master commands.
* **Active-LOW Relay Integration:** Safe and stable switching mechanism for high-voltage loads.
* **Modular C/C++ Codebase:** Clean, structured, and easy-to-scale Arduino code.

---

## 🛠️ Hardware Components Used
1. **Arduino Uno** (Microcontroller)
2. **VC-02 Voice Recognition Module** (Speech processing)
3. **4-Channel Relay Board** (Appliance control)
4. **Connecting Wires & Power Supply**

---

## 💻 Code Snippet Overview
The system listens to serial data from the voice module and executes corresponding relay actions using optimized `switch-case` logic in C++.
